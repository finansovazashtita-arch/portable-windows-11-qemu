# Полша KSeF Gateway (M79)

Интеграция с полската държавна портална система KSeF (Krajowy System e-Faktur) към Министерството на финансите на Полша. Генериране на FA(2)/FA(3) XML фактури, NIP валидация по Modulo 11, Session Token автентикация, XAdES дигитален подпис, сваляне на UPO разписки и реално време проверка на компании през GUS BIR1.1 API.
