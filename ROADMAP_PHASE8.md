## 🎯 Proposed Milestones

- **Benefit**: Ensures full compliance with EU digital invoicing directives (EN 16931).

### 2. **M32: Native Mobile Push Notification Gateway (Apple APNs & Firebase FCM)**
- **Scope**: Direct integration with Apple Push Notification service (APNs) and Firebase Cloud Messaging (FCM) for instant push alerts to mobile devices upon fraud detection.
- **Benefit**: Provides real-time instant alerts on mobile hardware.

### 3. **M33: Autonomous Audit Log Cold Storage Archiving (10-Year NRA Compliance)**
- **Scope**: Automated ZSTD compression and cold-storage archiving of HSM-signed `TRANSFER.LOG` files meeting statutory 10-year Bulgarian tax retention requirements.
- **Benefit**: Reduces storage footprint while ensuring total legal compliance.

### 4. **M34: Prometheus & Grafana Cluster Telemetry Exporter**
- **Scope**: Native Prometheus `/metrics` exporter monitoring transaction throughput (€/sec), OCR precision (%), and QEMU VM RAM usage.
- **Benefit**: Real-time visual cluster telemetry and performance monitoring.
